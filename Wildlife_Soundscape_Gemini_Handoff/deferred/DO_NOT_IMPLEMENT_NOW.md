# Deferred Features — Do Not Implement in This Cycle

These are valid future ideas but intentionally out of scope:

- ESP32 MicroSD outage backfill
- battery voltage telemetry
- solar charging telemetry
- LoRa
- autonomous field power management
- fourth sensor node
- 3D source localization
- target-species Telegram/Discord/MQTT alerting
- native mobile application
- cloud storage
- protocol v5

Reason:
the baseline must first produce measured software, synchronization and
localization performance. Field-hardening should be a separate revision.
